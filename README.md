# HIV Mortality Prediction and Model Reliability
## Project Overview

This project was developed as part of the Data Quality
course at the UPV Universitat Politècnica de València.

The objective was to develop and evaluate a machine
learning model for HIV mortality prediction, focusing
on predictive performance, probability calibration,
and fairness.

## Dataset
The project uses the AIDS Clinical Trials Group
Study 175 dataset.

The dataset contains clinical information about
patients participating in an HIV clinical trial.

## Technologies
- R
- RStudio
- Random Forest
- SMOTE
- Machine Learning
- Data Preprocessing
- Model Evaluation

## Methodology
The project includes:

1. Exploratory data analysis and preprocessing.
2. Feature selection.
3. Class imbalance handling using SMOTE.
4. Random Forest model training.
5. Model performance evaluation.
6. Probability calibration.
7. Fairness analysis.

## Model Evaluation
The predictive model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Brier Score
- Log Loss

## Probability Calibration
Different calibration techniques were investigated:

- Platt Scaling
- Isotonic Regression
- Quantile Binning
- Temperature Scaling

The objective was to assess the reliability
of the predicted probabilities.

## Fairness Analysis
The project investigated potential differences
in model predictions across demographic groups.

The analysis included:

- Demographic Parity
- Equalized Odds

## Project Context
Academic project developed for the Data Quality
course at the UPV Universitat Politècnica de València.

The project is intended for educational and
research purposes only.
